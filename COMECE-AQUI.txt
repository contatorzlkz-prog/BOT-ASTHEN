ASTHEN BOT — INÍCIO RÁPIDO

1. Extraia o ZIP.
2. Execute INSTALAR.bat.
3. Informe o token e o Application ID do seu bot Discord.
4. Execute INICIAR.bat.
5. No Discord, use /configurar para escolher os canais e o cargo da equipe.

KITS DA LOJA

1. Crie os kits reais no Minecraft pelo Plugin-ASTHEN.
2. Defina preço e disponibilidade no Minecraft, por exemplo: /dk price Kit_Ferro 29,90.
3. Aguarde o plugin sincronizar. Os kits aparecem automaticamente na loja do Discord.
4. Use /kit listar para conferir os kits e /kit editar para mudar nome exibido, descrição ou imagem.

Não existe cadastro de kit pelo Discord. O bot não altera os itens, preço ou disponibilidade oficial do Minecraft.

SEM PLUGIN CONECTADO

A loja mostra um Kit Demonstração para conferir o visual. Esse demo não abre pedido, não gera Pix, não reserva estoque e não entrega itens. Ele desaparece na primeira sincronização do plugin.

SUPABASE

1. Abra o SQL Editor do Supabase.
2. Execute o arquivo completo supabase/SETUP.sql.
3. No .env, preencha SUPABASE_URL e SUPABASE_SECRET_KEY.

IMPORTANTE

- Mantenha .env e toda a pasta data ao atualizar.
- Nunca compartilhe o .env, DKB_SECRET ou a chave do Supabase.
- O pagamento é conferido manualmente pela equipe.
- A aprovação depende do Supabase para reservar o estoque semanal.
