# Contribuindo

Obrigado por ajudar a melhorar o ASTHEN BOT.

## Antes de enviar
1. Abra uma issue descrevendo o problema ou a melhoria.
2. Mantenha as dependências essenciais e evite incluir APIs pagas.
3. Não envie tokens, chaves Pix, comprovantes ou dados privados.
4. Preserve compatibilidade com Windows 10/11 e Linux quando possível.

## Verificações
- Execute npm install.
- Execute npm run check.
- Descreva manualmente o cenário testado. Não declare testes que não foram feitos.

## Pull requests
Explique o objetivo, liste os arquivos alterados e inclua passos para reproduzir ou validar a mudança.
