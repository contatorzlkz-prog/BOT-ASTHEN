# Segurança

Não publique tokens de bot, chaves Pix, comprovantes, transcrições privadas ou arquivos .env.

Para reportar uma vulnerabilidade, não abra uma issue pública com credenciais ou dados exploráveis. Entre em contato com o mantenedor pelo perfil do GitHub e descreva o impacto sem incluir segredos de terceiros.

Cada instalação deve gerar seu próprio token no Discord Developer Portal. Em caso de vazamento, revogue e gere outro token imediatamente.
